# Decisions

> **Navigation**: [Documentation Root](../README.md)

One file per decision, named for its subject, recording the date, who decided, the
options considered and the reason for the choice. A superseded decision stays, marked
with what replaced it. Start each one from [`TEMPLATE.md`](TEMPLATE.md).

- [`NAMING_AND_PORTS.md`](NAMING_AND_PORTS.md), the repository, package and command names across the Python, Rust and Keleusma implementations, decided 2026-10-25.
